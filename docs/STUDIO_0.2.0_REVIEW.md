# 0.2.0 新版 Studio UI 验证包

本包按用户要求先交付用于 DBX 安装验证，不代表原计划的全部业务和 Windows 7 实机验收已经完成。

## 本次变更

- 活跃前端改为官方仓库 `web/` 的 RocketMQ Studio 3.0，固定提交 `0228dad5b9c9460f3e18c5c3e2b56c6525856198`。旧 2.1.0 `frontend/` 不再参与构建。
- 直接复用上游业务页面、侧栏、主题、筛选、表格、展开行和弹窗。首页改为上游监控总览，移除 AI 和控制台登录、退出、模拟数据开关。
- 连接与凭据仍由 DBX 管理；请求经 `studio/request` 调用 Go Sidecar。
- 本轮范围仍是原有 RocketMQ 管理功能，不扩展 K8s、多云及告警通知平台。

## 已执行检查

- TypeScript 构建、Vite 生产构建及上游许可证校验。
- Go 单元测试；新增 Studio 写操作只读保护和路由检查。
- 隔离 RocketMQ 5.3.3 集成测试通过：Topic 创建/查询/路由/导出/删除；Group 创建/列表/详情/订阅/进度/配置/导出/删除；实际发送、消息查询、队列浏览；位点预览与重置；集群、Broker 配置差异、NameServer 差异；生产者与客户端列表；ACL 用户/规则读取。原始输出：`studio-integration-5.log`。
- 在 DBX 开发宿主的实际 iframe 中打开新版首页及 Group 页面，确认原生 Studio 布局加载。
- Windows x64 Sidecar 使用 Go 1.20.14；打包时执行 PE 导入检查及安装包文件 SHA-256 完整性校验。

## 仍待验收与已知差异

- 原生 DBX 安装/升级、原生文件保存、Windows 7 + WebView2 109 实机运行由本次安装验证确认。
- 新 Studio 适配层尚未完成 4.9.x 全链路回归、在线消费者的全部诊断、轨迹、DLQ 重发与 Excel 导出、ACL 全部写入、全部多连接/网络故障场景的验证。旧接口测试结果不能等同于新版 UI 验收。
- 上游集群页面内仍有连接注册/K8s 相关控件及平台操作，尚未全部清理；这些平台接口未登记，调用会明确报错。DBX 连接配置仍应在宿主连接表单操作。
- Group 监控配置在旧后端中保留，新版 UI 的入口尚未对接。ACL 凭据查看、策略身份修改仍需进一步适配。
- Broker 未提供的创建/修改时间和未知统计不会编造；今日消息数缺少可靠数据时显示无数据。历史仅在连接期间采集。
- 当前未声明完整功能交付；请先验证新版 UI、连接和主要业务操作。
